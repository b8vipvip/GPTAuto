# GPTAuto v0.15.4

Performance/liveness release focused on reducing wall-clock time without weakening the canonical completion gates.

- Repair patches run targeted syntax/test validation before they are pushed and before a full CI cycle is spent.
- Clearly transient infrastructure failures receive one `rerun-failed-jobs` retry, never a whole-run retry loop.
- PR synchronize events cancel queued/running product workflows that belong to superseded heads.
- `workflow_run: in_progress` observations coalesce short CI runs for up to two minutes before handing off to Executor.
- The five-minute watchdog is recovery insurance only; it skips PRs whose exact-head CI is still normally queued/running.
- Consumer repositories can combine these controls with path-selective CI, dependency caches, and exact-SHA CI artifact reuse in Release.
