# GPTAuto v0.15.1

- Enables Copilot CLI local sandbox correctly with `--experimental --sandbox`.
- Restricts Tier 2 to file-only tools: `apply_patch,create,edit,view,grep,glob`, with file write approval and no shell/network/push/merge/release tools.
- Adds `operation=uninstall` to `GPTAuto Consumer Sync`, producing a CI-gated uninstall PR instead of requiring manual file deletion.
- Adds consumer install/update/uninstall guidance in `docs/CONSUMER_MANAGEMENT.md`.
